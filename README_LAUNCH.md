After cloning:

1. **backend/.env** - Add Supabase credentials
2. **frontend/.env.local** - Set API URL
3. **database/schema.sql** - Run in Supabase

## 🎓 Next Steps

1. Read `LAUNCH.sh` for complete instructions

- Use Supabase free tier for development
- Keep .env files private (in .gitignore)
